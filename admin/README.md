# YUS Textile — админка

Админка работает на Next.js (App Router), React и TypeScript. Требуется Node.js 20.9+ и запущенный API из `backend` на `http://localhost:4000`.

## Запуск

```powershell
cd admin
pnpm install
pnpm dev
```

Откройте `http://localhost:3001` и войдите с `ADMIN_EMAIL` и `ADMIN_PASSWORD` из настроек backend. Для production-сборки используйте `pnpm build`, затем `pnpm start`.

Адрес API задаётся переменной `API_ORIGIN` (по умолчанию `http://localhost:4000`). Next.js перенаправляет `/api/*` и `/uploads/*` в backend через `next.config.ts`, поэтому браузеру не нужен CORS для локальной админки. Административный API-ключ не попадает в браузерный код. Токен входа хранится только в `sessionStorage` текущей вкладки.

## Структура

```text
src/
  app/                маршруты Next.js и глобальные стили
  components/
    layout/           боковое меню, вход и сообщения
    dashboard/        главная страница
    resources/        списки и формы контента
    orders/           заявки и статусы
    site/             страницы «О нас» и контактов
    newsletter/       подписчики
    ui/               общие элементы интерфейса
  lib/
    api.ts            все запросы к backend и сессия
    resources.ts      описания разделов и полей форм
    types.ts          типы данных
    format.ts         форматирование и подписи
public/              логотип
```

Все формы для контента создаются из описаний в `src/lib/resources.ts`. При добавлении нового раздела достаточно описать поля и добавить ссылку в `navigation`.

Для товаров, категорий, комплексов и статей адрес страницы создаётся автоматически из первого названия, которое начали вводить (на русском, туркменском или английском). Администратор видит готовый адрес, но не вводит его вручную. У существующей записи адрес сохраняется при редактировании названия.

Переключатель «Язык просмотра» находится внутри каждого раздела контента над списком или текстом. Он меняет язык списка, карточки предпросмотра и данных страниц «О нас» и «Контакты». Язык запоминается в этом браузере. Кнопка с глазом в строке открывает предпросмотр записи; отсутствующий перевод показывается явно. В форме редактирования вкладки языков управляют полями отдельно. Выход из аккаунта требует подтверждения.

Удаление записи, изображения или характеристики и выход из аккаунта подтверждаются в диалоге админки. При удалении записи диалог показывает её название и предупреждает, что действие нельзя отменить.

В списках контента статус «На сайте» или «Скрыто» — это кнопка: нажмите её, чтобы сразу изменить видимость записи без открытия формы.

Поля больших текстов открываются в редакторе с увеличенной областью ввода, кнопками для абзаца, новой строки и списка, счётчиком слов и предпросмотром. Текст сохраняется с обычными переносами строк, которые публичный сайт уже отображает.

## Перенос контента со старого сайта

Импорт из `yustextile-web-main` выполнен скриптом `scripts/import-site-content.mjs`. Он сопоставляет товары по пути изображения (ID в языковых файлах расходятся), загружает изображения и PDF через API и пропускает уже созданные записи.

Предварительный просмотр:

```powershell
node scripts/import-site-content.mjs --source "C:\Users\Azat\Desktop\code\yustextile-web-main"
```

Повторный импорт при необходимости:

```powershell
node --env-file=../backend/.env scripts/import-site-content.mjs --source "C:\Users\Azat\Desktop\code\yustextile-web-main" --apply
```

Скрипт использует `ADMIN_EMAIL` и `ADMIN_PASSWORD` из backend `.env` только для входа в локальный API. Сопоставление загруженных файлов хранится в `scripts/.import-manifest.json` (файл игнорируется Git). Пять товаров с неполными переводами пропущены; PDF-каталог привязан только к русскому языку, так как его содержимое русскоязычное. Раздел блога не заполняется: статей в исходном сайте нет.
